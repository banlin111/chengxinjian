## 4. 当前已经实现的后端

代码位于仓库 `server/`。

另外提供 `/actuator/health`、`/actuator/health/readiness`、`/actuator/health/liveness`，不公开内部详情。

已落地的行为：

- 统一响应、参数与 JSON 校验、异常映射、服务端请求 ID、日志关联、Cache-Control/no-store。
- BCrypt 密码哈希；数据库不保存明文访问/刷新令牌，而保存 SHA-256 摘要。
- 当前令牌是安全随机生成的 opaque token，不是 JWT。不要因为模板存在 TOKEN_SIGNING_KEY 就以为 JWT 已实现或必须先索取该密钥。
- access/refresh TTL 默认分别为 2 小时/30 天；刷新时同时轮换两种令牌，旧值失效；登出撤销目标会话。
- 管理员禁用、角色权限变更在后续请求中实时生效；按 IP 与用户名+IP 窗口限流。
- 分类支持创建、详情、分页、名称搜索、状态筛选、修改、归档。
- 匿名分类接口只显示指定 kind 下的 published 数据。
- 分类管理要求 `content:read` 或 `content:write`，own_content 账号不能管理全局分类。
- 创建分类保存请求指纹和最初响应快照；同键同体重放原结果，同键异体返回 409；并发重试只创建一次。
- 修改检查 version；归档保留原记录，重复归档不会重复写审计。
- 认证数据库故障返回统一 503，不回传连接细节。

`V1__admin_and_catalog_foundation.sql` 已建 10 张表：
`admin_account`、`admin_role`、`permission`、`admin_account_role`、`admin_role_permission`、`auth_session`、`login_throttle`、`content_category`、`idempotency_record`、`audit_log`。
