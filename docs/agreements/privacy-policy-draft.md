## 1. 适用范围与选择

本政策说明澄心涧微信小程序及其配套服务如何处理个人信息。我们仅为明确、合理的目的处理必要信息，不默认索取通讯录、精确位置、健康病历或身份号码。您可浏览已开放的公共内容；需要账号的功能在您阅读协议并主动同意后启用。每项可选授权在使用对应功能时单独说明。

下表区分当前登录模块与拟开放功能。拟开放功能在实际接入、完成说明和必要授权前不应开始收集；正式政策应根据发布版本删去未开放能力，并补齐供应商及期限，不能将规划描述成已经发生的数据处理。

## 2. 处理哪些信息、为何处理

| 功能 | 信息与来源 | 目的及不提供的影响 |
| --- | --- | --- |
| 微信登录（当前开发模块） | 微信提供的小程序身份标识 OpenID，适用时提供 UnionID；服务生成的用户编号、注册和最近登录时间 | 识别本小程序账号和维持登录；不授权则不能使用需登录的功能，公共内容浏览不受影响。不以 OpenID 作为对外业务编号 |
| 协议确认（当前开发模块） | 协议类型、版本、同意时间和请求编号 | 记录您阅读并同意的版本，处理授权争议 |
| 登录安全（当前开发模块） | 登录会话凭据摘要、有效期、撤销状态；由连接来源得到的 IP 用于生成限流摘要；操作类型、用户编号、请求编号和时间 | 验证访问权限、限制滥用、排查错误；不在业务日志中记录 AppSecret、明文会话令牌或微信 session_key |
| 偏好设置（当前开发模块） | 主题、播放偏好、提醒开关和时间 | 保存您的选择；关闭提醒不影响学习。保存开关不等于取得微信订阅消息授权 |
| 手机号与密码（拟开放） | 您输入或单独授权提供的手机号、验证码校验结果、密码安全摘要 | 注册、绑定、找回及必要身份核验；不收集则相应手机号功能不可用。微信账号不因未绑定手机号就被阻止使用不依赖手机号的服务 |
| 昵称头像（拟开放） | 您主动填写的昵称、选择上传的图片 | 展示个人资料；不要求读取整个相册，可通过系统选择器选取单个文件 |
| 学习、练习和打卡（拟开放） | 课程或课节编号、有效播放/练习时长、进度、完成时间、打卡日期 | 保存记录、核算活动资格；不用于推断疾病、宗教信仰等敏感属性 |
| 评论与直播互动（拟开放） | 您提交的文字、关联内容、昵称、互动时间和必要审核信息 | 提供互动和审核；提交前说明公开范围；不填写则不产生相应互动 |
| 练习录制（拟开放，可选） | 您主动录制并提交的音频/视频/文字及审核结果，具体形式待确认 | 审核活动资格。录制前说明访问人员、保存期限、撤回方式和必要性，依信息性质取得单独同意；拒绝不影响无录制要求的服务 |
| 订单与支付（拟开放） | 商品、金额、订单状态、支付平台交易标识、退款状态和必要权益记录 | 履行购买、退款及对账；支付密码和银行卡完整信息由支付平台处理，我们不收集 |
| 实物寄送（拟开放，可选） | 您填写的收件人、联系电话、地址及运单和物流状态 | 配送所选奖励及处理售后；不提供则无法寄送，可继续使用不依赖配送的功能 |
| 提醒（拟开放，可选） | 您主动选择的提醒事项、微信订阅授权结果及发送状态 | 发送您选择的服务提醒；拒绝或关闭不影响主要功能，不默认发送营销消息 |

我们不在当前版本接入广告画像或将个人信息用于模型训练。如未来改变处理目的、方式或信息种类，先告知并依法重新取得同意。

## 3. 权限与公开范围

麦克风、摄像头或文件选择仅在您主动使用相应录制/上传功能时按需调用；具体权限以实际录制方案为准。拒绝可选权限仅影响对应功能，您可以在微信或系统设置中管理授权。

您的地址、手机号、订单、学习记录及练习录制默认不向其他用户公开。您主动发表的评论或直播消息，按发表前提示的范围展示昵称及内容。录制用于资格审核，不因参加活动就被公开；如另需公开展示，说明范围、期限和风险并取得单独同意。管理员按职责授权访问，访问敏感资料应留存必要审计记录。

## 4. 服务商与信息提供

微信为登录等平台能力的提供方，其个人信息处理规则适用于其独立提供的服务。我们向微信发送小程序登录凭证以验证身份；微信 session_key 不返回客户端，当前登录实现不保存该值。

云计算已选腾讯云账号，但服务器、存储、短信、直播等具体产品尚未开通确认。**正式发布前必须在此列出实际服务商主体、产品、用途、处理的信息、联系方式或隐私政策链接、受托处理或独立处理关系及服务区域。未接入的服务不得伪列为已接入。**

配送或其他独立服务如需向第三方提供个人信息，我们会告知接收方、目的、方式和信息范围，并依法取得单独同意；依法无需同意的情形按规定处理。我们不出售个人信息。因合并等需转移个人信息时依法告知，并要求接收方继续履行相应保护义务。

## 5. 保存位置、期限与删除

部署目标为中国大陆境内；上线前核实具体区域、访问控制及备份位置。目前未配置跨境提供；如确需跨境，履行适用条件和告知、同意义务后再开展。

账号与偏好仅在提供账号服务所需期限内保存；协议记录、订单、履约、安全日志分别按目的和适用法定义务保存，不使用“永久保存全部数据”的规则。撤回同意、目的完成或注销后，按适用条件删除或匿名化。法律规定期限未届满或删除从技术上难以实现的，停止除存储和必要安全保护以外的处理。

## 6. 安全措施与事件处理

采用 HTTPS、访问权限分离、密码安全哈希、令牌摘要、敏感信息脱敏等措施；在上线前落实部署、备份恢复与访问审计。我们不承诺任何系统绝对安全。发生个人信息安全事件时，及时采取补救措施，并按适用法律要求履行告知和报告义务。

## 7. 您的权利与联系我们

您可以查阅、更正、复制自己的个人信息，管理授权、撤回基于同意的处理、申请删除或注销，或要求解释个人信息处理规则。设置中已经提供的入口可直接使用；入口尚未开放或无法完成时，通过上方联系方式申请，不因此失去权利。

我们只进行与申请风险相适应的必要身份核验，不要求无关敏感材料。撤回同意不影响此前合法处理的效力；如某项处理属于提供相应服务所必需，会说明撤回对该项服务的具体影响。我们将及时处理申请，并在不能满足时说明原因和申诉途径。

【上线前填写：真实有效的受理渠道、核验方式、答复时限及投诉路径，并安排实际受理人员。】

## 8. 未成年人

涉及不满十四周岁未成年人的个人信息，须取得监护人同意并制定专门规则。在完成监护人核验和专门保护流程前，不向该人群开放注册、录制和付费服务；正式年龄机制须由甲方确认并实际实现。发现不符合要求收集的信息，及时核实并依法处理。监护人可通过上述渠道联系我们。

## 9. 政策更新

政策保持便于查阅、保存。重大变更以显著方式说明，涉及依法需重新同意的事项在取得同意后实施；历史版本保留查阅。不会把一次注册勾选作为后续全部数据处理的概括授权。
