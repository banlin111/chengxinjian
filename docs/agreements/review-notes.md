# 协议草案确认说明

2026-11-09 用户澄清：甲方尚未形成正式协议，需要开发方拟稿。本目录两份正文是可审阅草案，未导入数据库、未批准、未生效。只有 local profile 的明显测试文本用于本地联调；非 local 环境不读取测试文本。

甲方现在只需确认：

1. 两份协议中的运营主体全称、联系地址、有效客服及隐私联系邮箱/电话。
2. 阅读正文，标注需修改的内容；确认服务面向的年龄范围，以及是否接受“不满十四周岁专门流程完成前不开放该人群注册”的拟定方案。
3. 修改完成后，指定确认人，书面确认最终版本和生效日期。草案不能直接当作正式批准文本。

销售、录制、奖励等具体数字在各功能启用前分批确认，不要求现在一次填完。当前尚未实现注销执行、未成年人核验、提醒发送等完整能力；正文相关承诺必须在这些能力上线并验收后才能发布。

开发方核查依据（2026-11-09）：

- [《中华人民共和国个人信息保护法》官方全文](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)：告知和同意、最小必要、保存期限、敏感信息和未成年人、查阅删除等要求。正文为本项目原创草案，不构成甲方批准或正式法律审定。
- [微信小程序用户隐私保护说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)：正式小程序的隐私声明及平台授权流程还需前端与运营后台共同落实；服务端保存协议记录不能替代微信隐私授权。

拟定的年龄限制和处理方案只是供确认的选择，不代表已在当前账号接口中实施年龄核验。正式启用前需补齐实现与验证。
