# 本阶段给甲方的腾讯云准备步骤

> 此准备工作已由开发方按用户授权代办，甲方无需重复操作或再次交付密钥。实际完成范围与验证结果见 [开通记录](cloud-setup-2026-11-10.md)。下文保留原准备步骤。

2026-11-10 用户澄清：甲方当前只有腾讯云账号，尚无已交付的项目子账号或存储桶。当前只准备开发联调存储和受限的服务端访问身份，不采购服务器或域名；公共部署时另给清单。

以下段落可直接转发甲方。请一并转发开发方准备的 `cos-dev-policy.json` 文件；该文件只包含项目桶范围和权限，没有密钥，已按已登记的腾讯云 APPID 填好。实际文件在本机 `server/.local/cloud-bootstrap/cos-dev-policy.json`，被 Git 忽略。

---

为调试澄心涧的图片和音视频上传，请在腾讯云完成下面三步：

1. 创建开发用文件存储
   - 腾讯云控制台搜索“对象存储 COS”→“存储桶列表”→“创建存储桶”。首次使用时按平台提示开通服务。
   - 名称填写 `chengxinjian-dev`（数字后缀由平台追加）；类型选“通用存储桶”；地域选“上海”；权限选“私有读写”；存储采用标准、单 AZ，用于开发联调。
   - 完成后保存“完整存储桶名称”和“所属地域”。如果完整名称与授权文件中的名称不同，请先把实际名称回复我们，我们调整文件。

2. 添加本项目授权
   - 控制台搜索“访问管理”→“策略”→“新建自定义策略”→“按策略语法创建”→“空白模板”。
   - 策略名称填写 `cxj-media-dev`，把随消息收到的 `cos-dev-policy.json` 全文粘贴到策略内容框，点击“完成”。
   - 这份授权仅用于上一步的开发桶，包含上传、读取、校验、清理测试文件以及配置网页上传所需的跨域规则，不包含全账号管理或支付权限。

3. 创建服务端专用子用户
   - “访问管理”→“用户”→“用户列表”→“新建用户”→“自定义创建”→“可访问资源并接收消息”。
   - 用户名填写 `cxj-media-dev`，备注填写“澄心涧媒资联调”；访问方式勾选“编程访问”，不需要开通控制台访问。
   - 在“设置用户权限”中关联第二步的 `cxj-media-dev` 策略，完成创建并保存生成的 SecretId、SecretKey。如果创建完成页未显示密钥，在该子用户详情的“API 密钥/访问密钥”中创建一组。

完成后请私下交付：完整存储桶名称、地域、子用户名/账号 ID，以及这个子用户的 SecretId、SecretKey。不要交付主账号密码或主账号 API 密钥，也不用重发微信 AppSecret。

云存储有存储量、请求等使用费用；本阶段用于开发联调，正式生产资源规格另外确认。

## 开发方自行完成

接收后核对桶名与授权范围，将子用户密钥存入受保护、忽略 Git 的本地配置；实际验证身份、私有桶、临时票据、上传/校验与清理。CORS、接口适配、代码及配置由开发方处理。当前没有访问甲方控制台、创建资源、提交授权或验证密钥，不把准备文件当实际开通成功。

本策略没有列举全部存储桶、创建/删除桶、修改桶公开权限、跨账号授权或购买资源权限。未来生产服务使用独立身份和资源，按实际部署需要重新限定。
