# 安卓普通预览排查

当前预览版本：`2026-11-11.android.2`。

## Android 普通预览回传与修复

Android 16、微信 8.0.79、基础库 3.17.6 的 `android.1` 日志两次记录：`Component is not found in path "components/PlayerTransition" (using by "pages/home/index")`。本地输出中的组件文件与页面引用大小写一致，尚无法确认手机端为何没有加载该文件；已确认具体失败的是该组件依赖。

在 `android.2` 中，把展开框、封面和全屏回退合入已有的 `PlayerScene`。首页、练习、课程详情、冥想详情、直播都直接渲染同一个播放器，移除独立的 `PlayerTransition` 文件和引用。保留点击展开、原地播放和返回清理。新增微信构建后的组件路径检查，按大小写核对每个页面递归引用的组件及其 JS、JSON、WXML 文件。

从新目录构建并生成普通预览码 `research/weixin-preview-android-1111-2.png`。类型检查、H5 和微信构建、56 项浏览器回归均通过；核对了 25 个页面、5 个原生组件，确认新包没有旧组件引用。微信开发者工具的原生自动化超时，待使用该二维码验证安卓普通预览。

以下保留 `android.1` 的排查记录。

## 用户现象与结论边界

普通扫码预览：底栏“练习”空白，首页卡片无法打开。切换真机调试后用户反馈可正常使用；手机为 Android。暂未取得故障时的普通预览错误日志，因此尚未确认根因，不能把调试模式正常视为修复完成。

## 本轮代码审查与调整

- 首页、课程详情、冥想详情、练习、直播的播放器过渡层只在打开或过渡期间挂载；原生 page-container 只在播放器打开时创建，减少空闲页上的原生组件。
- PlayerTransition 对尚未传入的 state 使用空状态，避免组件初始化时直接读取缺失属性。属于防御性修复，尚未证明这是手机故障根因。
- 保留原有统一展开动画、原地播放器与返回逻辑，未修改业务接口。
- 增加 develop 环境的本机诊断：Vue、App 与未处理 Promise 错误最多保存十条，每条最多两千字符，附版本和页面路径；不自动上传。设置页底部可复制系统/微信/基础库版本及错误记录。release 环境不启用记录和入口；存储失败不会打断页面。

## 已完成验证

- 类型检查、H5 与微信构建通过；最终微信包重新构建并成功生成普通预览码。
- 56 项浏览器回归通过，包含冷启动五个底栏切换、返回首页打开卡片和练习领取操作。
