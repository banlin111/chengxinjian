## 你现在做的核实（开发人员自己的操作）

1. 打开 [腾讯云登录页](https://cloud.tencent.com/login)，使用你自己的微信/QQ等方式登录。
2. 若出现“选择用户身份”，检查是否有对应甲方的“协作者”身份。选择该身份，在下拉框中选择甲方后登录；核对控制台当前所属账号是否为甲方。
3. 如果甲方曾交付子用户，使用已交付的子用户快速登录链接；或选择“子用户登录”，填 `子用户名@主账号ID` 和你自己的子用户密码。不要使用甲方主账号密码。
4. 记录结果即可：能否以甲方项目身份登录，以及访问“对象存储 COS”时是否提示无权限。不创建资源、不购买套餐，不发密码或验证码。
5. 如果仅能进入自己的主账号、没有甲方协作者身份，同时也没有子用户登录信息，只能说明尚未核实到开发授权；请让甲方按下面这段话查一次。

以上开发人员登录工作由开发人员完成，不转交甲方。

## 可直接发甲方的核实文字（当前只需核实这一项）

> 为接下来调试课程图片和音视频上传，请您核实腾讯云是否已添加我们的开发账号：
>
> 1. 登录甲方腾讯云控制台，顶部搜索“访问管理”，进入“用户 → 用户列表”。
> 2. 查看是否已有给我们项目创建的子用户或协作者。
> 3. 如有，请回复账号备注/子用户名、账号 ID、采用“子用户”还是“协作者”，以及已关联的权限策略名称；不发送主账号密码或主账号 API 密钥。
> 4. 如没有，请回复“尚未添加”。我们会先提供开发人员自己的账号 ID 和本阶段所需的授权内容，再请您添加。
>
> 这一步只核实已有授权，暂不需要购买资源。

## 核实后的分流

- 已有可用授权：由开发方检查资源权限，再为真实媒资联调准备项目私有存储及专用服务身份，权限限制到项目所需资源。
- 尚未添加：先取得开发者自己的腾讯云账号 ID，再给甲方一份可直接填写的新增协作者步骤；不能把甲方主账号 ID 填成开发者 ID。
- 存在账号但权限不足：记录具体被拒绝的资源操作，再按实际需要补授权，不默认申请全账号管理员权限。

服务器、域名和 HTTPS 属于后续公共联调/部署阶段，将根据实际部署方案另给甲方清单。当前代码继续在本机开发，不等待全部云资源齐备。
