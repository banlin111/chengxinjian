# 澄心涧小程序前端

使用 uni-app CLI + Vue 3 + TypeScript + Pinia，不需要 HBuilderX。依赖版本由 package-lock.json 固定。工程基于 DCloud 官方 vite-ts 模板的依赖组合；当前使用 Node 24 / npm 11 验证。

## 启动预览

在仓库根目录执行：

```powershell
npm --prefix apps/mobile ci
npm run dev:mobile
```

浏览器打开 http://localhost:5173。修改源文件后自动刷新。H5 适合查看布局、主题和点击效果；微信专有能力必须在微信工具和真机验证。

## 微信开发者工具

另开终端，在仓库根目录执行：

```powershell
npm run dev:weixin
```

将 `apps/mobile/dist/dev/mp-weixin` 导入微信开发者工具，不能导入源码目录。命令保持运行，保存源文件后自动重新编译。发布构建使用 `npm run build:weixin`，输出在 `apps/mobile/dist/build/mp-weixin`。

已在 `src/manifest.json` 的 `mp-weixin.appid` 配置甲方小程序 AppID。微信开发者工具需使用具有该小程序开发权限的微信登录，方可扫码预览、真机调试或上传。配置 AppID 不代表登录、支付等后端能力已接通。AppSecret 和云平台密钥不进入前端或仓库；腾讯云账号资料无需用于本地 UI 预览。微信实机尚未验收。

2026-11-10 已通过微信开发者工具原生 WXSS 编译并成功生成手机预览二维码，预览包约 1.8 MB。修复了通配选择器和 Tailwind 列表选择器的微信兼容问题。二维码存于忽略提交的 `research/` 目录；这次操作是开发预览，没有发布正式版本。手机上的布局、交互和帧率仍待实机验收。

## 代码与接口协作

| 位置 | 职责 |
| --- | --- |
| `src/pages` | 页面与交互 |
| `src/components` | 页面外壳、标题等公共组件 |
| `src/config/screens.ts` | 22 页登记与统一跳转 |
| `src/composables/useScreenPreview.ts` | 本机演示状态和占位动作 |
| `src/styles/screens.css`、`polish.css` | 页面布局与阅读、触控细节 |
| `src/styles/prototype-utilities.css` | 生成的微信安全类名样式，执行 `npm run styles` 更新 |
| `src/stores/theme.ts` | 主题状态与原生底栏同步 |
| `src/services/home.ts` | 首页数据服务与隔离示例数据 |
| `src/services/http.ts` | 只读 GET 请求、统一错误，不在真实请求失败时切换为假数据 |
| `../../contracts` | 前后端共享类型定义，前端直接引用 |
| `src/static/reference/SOURCES.json` | 原型同源图片来源记录 |
| `src/static/prototype/SOURCES.json` | 其他页面的原型图片来源，资源已本地化 |
| `src/static/icons` | 本地图标与许可证 |

联调时复制 `.env.example` 为 `.env.local`，设置 `VITE_API_BASE_URL` 并将 `VITE_USE_MOCK=false`，重启编译器。首页使用契约中的 `GET /home`，要求后端返回统一 Envelope；这个开关目前只接管首页数据，其他页面仍使用本地样例。商城与直播可从个人中心进入。VITE 环境变量会进入前端包，只能放公开配置。认证、Token 刷新和写入幂等在相应业务批次实现。

### S6 助眠混音精修（2026-11-10）
